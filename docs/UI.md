# CLI + Web UI Design

## CLI

### Commands

```
$ brain serve                     MCP + Web 서버 시작 (기본 포트: 7777)
$ brain serve --port 8080         포트 지정

$ brain search "Python 리스트"    직접 검색
$ brain search "Python" --category programming  카테고리 한정

$ brain tree                      지식 구조 출력
$ brain tree --depth 3            깊이 지정

$ brain status                    건강 상태 + 통계
$ brain lint                      건강 체크 (상세)

$ brain import ./docs/            디렉토리 내 파일 대량 임포트 (raw/에 복사)
$ brain import ./report.pdf       단일 파일 임포트
$ brain export ./backup/          전체 데이터 백업 (wiki/ + raw/ + _meta.db)

$ brain db "SELECT * FROM projects"   SQL 직접 실행
$ brain db --schema               전체 스키마 출력

$ brain log                       최근 이벤트 로그 출력
$ brain log --last 20             최근 20개

$ brain config get                전체 설정 출력
$ brain config set max_file_size 200000  설정 변경

$ brain init                      새 데이터 디렉토리 초기화
$ brain init --dir ~/my-knowledge 경로 지정
```

### 출력 형식

기본: 사람이 읽기 좋은 테이블/트리 형태
`--json` 플래그: JSON 출력 (스크립트 연동용)
`--quiet` 플래그: 최소 출력

## Web UI

### 기술 선택 (구현 시 결정)

후보:
- Python: FastAPI + Jinja2 + HTMX (가볍고 빠른 개발)
- Python: FastAPI + React/Svelte (더 풍부한 UI)
- TypeScript: Hono/Express + React/Svelte

### 뷰 구성

Web UI는 6개 뷰로 구성:

```
┌──────────────────────────────────────────────────────────────┐
│  🧠 SuperPikachu                                             │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐     │
│  │그래프 │ │탐색기│ │검색  │ │DB    │ │타임라인│ │설정  │     │
│  └──────┘ └──────┘ └──────┘ └──────┘ └──────┘ └──────┘     │
└──────────────────────────────────────────────────────────────┘
```

### View 1: Graph (그래프 뷰)

지식 노드 간 연결을 인터랙티브하게 시각화.
3가지 모드: Constellation (2D), Galaxy (3D), Heatmap (분석).

**상세 설계는 [VISUALIZATION.md](./VISUALIZATION.md) 참조.**

핵심 컨셉:
- Dark-mode-first (우주/은하 메타포)
- 노드 크기 = 리콜 빈도, 밝기 = 활성도, 색상 = 카테고리, 형태 = 엔티티 타입
- 충돌 = 빨간 번개, 지식 갭 = 어둠 성운, 새 지식 = 성장 파문
- Sigma.js (2D) + 3d-force-graph (3D) + cosmos.gl (초대규모)
- 성장 애니메이션: 지식이 시간에 따라 쌓이는 과정을 재생

### View 2: Explorer (탐색기 뷰)

파일 시스템 스타일 좌측 트리 + 우측 MD 렌더링/편집.

```
┌──────────────┬─────────────────────────────────┐
│ 폴더 트리     │ MD 렌더링 + WYSIWYG 편집         │
│              │                                 │
│ 📁 wiki/     │ ┌─ python-basics.md ──────────┐ │
│ ├ 📁 programming │ │                         │ │
│ │ ├ 📄 python-basics.md │ # Python Basics    │ │
│ │ ├ 📄 git.md    │ │                         │ │
│ │ └ 📄 api.md    │ │ ## 리스트 컴프리헨션      │ │
│ ├ 📁 personal    │ │                         │ │
│ │ └ 📄 prefs.md  │ │ 리콜 47회 | 소스: 대화   │ │
│ ├ 📁 projects    │ │ 충돌 1건 ⚠️              │ │
│ └ 📁 archive     │ │                         │ │
│              │ │ [content here...]           │ │
│ ─────────────│ │                             │ │
│ 📁 raw/      │ └─────────────────────────────┘ │
│ ├ 📁 documents│                                │
│ └ 📁 urls    │ [Raw 원본] [편집] [아카이브]      │
└──────────────┴─────────────────────────────────┘

기능:
  - 트리에서 파일 선택 → 우측에 MD 렌더링
  - 편집 모드 전환 (WYSIWYG 또는 raw MD)
  - frontmatter 표시 (태그, 소스, 생성일, 리콜 수)
  - 충돌 표시 (해당 파일에 pending conflict가 있으면)
  - 파일 드래그&드롭으로 카테고리 이동
  - 새 파일/폴더 생성
  - 파일 업로드 (drag & drop → learn_document 트리거)
  - URL 입력 → learn_url 트리거
```

### 파일 업로드 UX

```
1. Explorer 뷰에서 drag & drop
   → 파일을 wiki 영역에 드롭
   → learn_document 트리거
   → 추출된 텍스트 미리보기 표시
   → "이 내용을 어디에 저장할까요?" (카테고리 선택 또는 MCP를 통해 LLM에게 위임)

2. 전용 업로드 패널
   → [파일 선택] 또는 [URL 입력]
   → 여러 파일 한번에 업로드 가능
   → 진행 상태 표시
   → 완료 후 raw/에 보존 + 타임라인에 기록

3. Web Clipper 연동 (향후)
   → Obsidian Web Clipper 또는 자체 브라우저 확장
   → 웹 기사를 원클릭으로 learn_url
```
