# Web 인터페이스 컨셉 (미구현)

English: [WEB_UI.md](WEB_UI.md)

## 상태

ohkb는 **웹 서버, 브라우저 UI, HTTP API, URL 가져오기, 원격 MCP transport를 제공하지 않습니다.** 지원하는 제품 표면은 로컬 CLI와 stdio 기반 MCP입니다. 이 문서는 미래에 검토할 수 있는 인터페이스 아이디어만 기록하며, 로드맵 확정이나 설치 옵션이 아닙니다.

## 제품 아이디어

사람이 에이전트와 동일한 Markdown + SQLite FTS5 지식 베이스를 탐색하고 정리하는 카탈로그를 생각할 수 있습니다. 이 인터페이스는 `KnowledgeBase`를 사용하는 뷰일 뿐이며, 채팅 제품이나 별도 원본 저장소가 아닙니다.

가능한 영역:

- 카테고리 트리와 검색 결과 탐색;
- 엔트리 읽기와 편집;
- status, lint, 자동 인덱스, 활동 이력 확인;
- 변경 불가능한 로컬 source 파일 검토.

## 하지 않는 일

- 모델·채팅·프롬프트·프로바이더 라우팅 호스팅;
- 모델 자격 증명 저장;
- CLI/MCP 에이전트 계약 대체;
- 범용 노트 앱 확장;
- 코어 패키지에 원격 서비스 도입.

## 향후 구현 전 보안 조건

코드를 추가하기 전에 별도 설계와 보안 검토가 필요합니다. 최소한 인증, 요청 위조 방어, 엄격한 로컬 바인딩 기본값, 원격 접근 정책, 경로 격리, 심볼릭 링크 처리, 입력·업로드 크기 제한, 의존성 격리, 보안 테스트를 정의해야 합니다. 구현은 `KnowledgeBase`만 호출하고 파일시스템 우선 dual-write를 유지해야 합니다.

이 조건이 설계되고 승인되기 전까지 Web은 문서 컨셉으로만 남습니다.
